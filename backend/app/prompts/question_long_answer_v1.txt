Field rules:
- body: 1-3 sentences. Phrase as a question OR a directive ("Explain how...",
  "Compare and contrast...", "Describe the process by which..."). End with
  '?' if a question, '.' if a directive.
- reference_answer: 3-6 sentences. Written as a model student response in
  complete sentences. No markdown bullets, no numbered lists. Demonstrates
  what full credit looks like.
- key_points: 3-5 entries. Each is a short noun phrase or clause naming ONE
  graded idea the evaluator should look for in the student's response. The
  evaluator does fuzzy matching, so each point should be specific enough to
  identify but flexible enough to accept reasonable paraphrasing.
- explanation: 1-2 sentences explaining WHY this is a good model answer —
  what reasoning chain or framework it demonstrates. Shown to the student
  AFTER they submit.

Content rules:
- Use ONLY the source material below. If you can't write a fair long-answer
  question whose reference answer is fully supported by the source, return
  {"insufficient_source": true} (see header).
- The question should require synthesis, explanation, comparison, or
  application — NOT pure recall (that's short_answer territory).
- key_points must each appear in (or be directly demonstrated by) the
  reference_answer. Don't list a key_point the model answer doesn't cover.
- Do NOT use "list" or "name three" phrasing — that produces short_answer
  cosplay, not essays. Prefer "explain", "describe", "compare", "contrast",
  "analyse", "interpret".
- No multi-part questions in one body ("Define X. Then explain Y."). Each
  question covers a single coherent prompt.

Difficulty calibration:
- beginner:     "Describe" or "Explain" a single concept from the source in
                the student's own words. Reference answer is a paraphrase of
                one paragraph.
- intermediate: "Compare", "Contrast", or "Explain how X relates to Y"
                across two ideas from the source. Reference answer
                integrates two distinct sections.
- advanced:     "Analyse", "Evaluate", or "Apply to a new scenario". The
                reference answer requires interpretation or synthesis the
                source supports but doesn't state directly.

Avoid duplication:
- Do NOT produce a question whose body closely paraphrases any entry in
  "Previously served question stems". Return {"insufficient_source": true}
  if the natural questions for this topic are exhausted.
