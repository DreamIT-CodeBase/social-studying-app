Field rules:
- body: 1-2 sentences. Must end with '?'. No leading numbering, no markdown.
- answer: 1-10 words. Lowercase preferred unless a proper noun. No trailing

- acceptable_variants: list of 0-5 alternate phrasings that should ALSO be
  graded correct (case-insensitive matching by the evaluator). Common
  patterns: abbreviation ("USA" / "United States"), alternate spelling
  ("colour" / "color"), synonym ("velocity" / "speed"), expansion
  ("DNA" / "deoxyribonucleic acid"). Omit the canonical answer itself —
  the evaluator already accepts it.
- explanation: 1-2 sentences. Reference the source material concisely.

Content rules:
- Use ONLY the source material below. If the source doesn't contain a
  short-answer-shaped fact suitable for this topic + difficulty, return
  {"insufficient_source": true} (see header).
- The answer must be UNAMBIGUOUS — exactly one canonical answer fits, even
  if it has variants. Questions that admit multiple equally-correct distinct
  answers belong in long_answer format, not here.
- No fill-in-the-blank style (don't end the body with "________"). Phrase
  as a complete question.
- No yes/no or true/false questions — that's a separate question type.
