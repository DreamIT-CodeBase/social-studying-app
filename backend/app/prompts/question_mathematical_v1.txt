Field rules:
- body: 1-3 sentences. Use $...$ for inline math (e.g. "Find the derivative
  of $f(x) = x^2 + 3x$."). End with '?' (question) or '.' (directive). No
  numbering, no markdown.
- answer: the FINAL answer only — not the full derivation. LaTeX-formatted
  if mathematical (e.g. "$2x + 3$", "$\\frac{1}{2}$"), or plain digits for
  pure numeric answers ("42", "3.14"). No units in the answer field unless
  the question explicitly asks for units; if units, write "$5\\,\\text{m/s}$".
- solution_steps: 2-5 entries. Each is one logical step. Each step states
  WHAT operation and (when applicable) WHY. Use LaTeX for any mathematical
  expressions inside steps. The evaluator uses these for partial credit if
  the final answer is wrong.
- explanation: 1-2 sentences naming the underlying rule, theorem, or concept
  (e.g. "Applies the Pythagorean theorem", "Quadratic formula with
  $a=1$, $b=-3$, $c=2$"). Shown after submission.

Content rules:
- Use ONLY the source material below for the FRAMING (which concepts,
  which formulas, which depth level). The numeric values in the problem
  may be original — you're not restricted to numbers that appear in the
  source. If the source doesn't establish the technique being tested,
  return {"insufficient_source": true} (see header).
- The answer must be deterministic — exactly one canonical form is correct
  (modulo equivalent LaTeX forms, which the evaluator handles).
- Show ALL non-trivial steps in solution_steps. A student who got the wrong
  final answer should be able to read your steps and find their mistake.
- No multi-part problems ("Solve part (a), then part (b)"). One problem per
  question.
- Pick numeric values that yield clean answers when possible (integer or
  simple fraction). Ugly decimals ("2.7182…") suggest the wrong example,
  not the right one.

Difficulty calibration:
- beginner:     Direct application of one formula with given values. ("Find
                the area of a rectangle with length 5 and width 3.") One
                solution step plus answer.
- intermediate: Two-step problem combining two concepts. ("Find the area
                under $y = 2x$ between $x=0$ and $x=3$.") 2-3 solution
                steps. The student needs to recognise WHICH formula applies.
- advanced:     Requires setting up the problem from a word description or
                applying a concept in a non-standard direction (e.g. solving
                BACKWARDS: "Given the area is 24, find the width when the
                length is 6"). 3-5 solution steps.

Avoid duplication:
- Do NOT produce a question whose framing closely paraphrases any entry in
  "Previously served question stems". Vary the numeric values AND the
  framing across questions. Return {"insufficient_source": true} if natural
  problems for this topic are exhausted.
